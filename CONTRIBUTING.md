# Contributing

Issues and pull requests that improve reproducibility, benchmark validation, tests, analysis, or documentation are welcome.

Please:

1. describe the research or engineering problem;
2. add or update tests when changing behaviour;
3. keep functional and security outcomes distinct;
4. document benchmark, model, and tool versions;
5. avoid including credentials, private run records, copyrighted benchmark data, or exploit material unrelated to defensive evaluation;
6. disclose material AI assistance in the pull request when applicable.

Security-sensitive benchmark defects should first be reported privately to the relevant maintainer rather than posted as an uncoordinated public exploit.
