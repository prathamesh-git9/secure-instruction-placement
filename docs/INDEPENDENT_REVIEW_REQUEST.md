# Independent methods review requested

The project is seeking critical review **before** confirmatory runs. Feedback can be left on [issue #1](https://github.com/prathamesh-git9/secure-instruction-placement/issues/1).

Useful reviewer backgrounds include empirical software engineering, software security, program analysis, AI-for-code evaluation, or applied statistics.

Please challenge:

1. whether the 2 x 2 placement design isolates the intended factors;
2. whether the audited 11-task subset and two exclusions are defensible;
3. whether task, run, weakness family, or another level should be the primary unit of analysis;
4. which contrasts and uncertainty intervals should be primary;
5. whether three repetitions per task-condition cell are informative enough;
6. how model stochasticity, version drift, benchmark-oracle error, and task dependence should be handled;
7. what evidence is required before the work is suitable for a short paper or preprint.

The public pilot observations must not be used to rewrite hypotheses. Reviewers are asked to focus on the pre-result design and to identify failure modes, missing literature, and overclaims.

Review does not imply endorsement or authorship. Authorship would require a separate, substantive scholarly contribution and explicit agreement.
